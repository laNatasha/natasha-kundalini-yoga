# Наташа — сайт личного бренда преподавателя кундалини-йоги

Премиальный адаптивный сайт личного бренда. Контент страниц и карточек хранится в `app.js`, поэтому новые ретриты, события, отзывы и статьи добавляются независимо от дизайна.

## Запуск

Откройте `index.html` через любой локальный сервер. Например:

```powershell
python -m http.server 4173
```

Затем откройте `http://localhost:4173`.

## Структура

- `index.html` — каркас, метаданные, навигация, форма
- `styles.css` — дизайн-система и адаптивные состояния
- `app.js` — страницы, контент и интерактивность
- `assets/images` — только реальные фотографии владельца
- `assets/video/natasha-intro.mp4` — основная веб-версия приветственного видео Наташи
- `assets/video/natasha-intro.mov` — сохранённый исходник и резервный формат
- `assets/video/pranayama-stress.mp4` — бесплатная дыхательная практика
- `assets/video/meditation-reset.mp4` — бесплатная медитация «Перезагрузка»

Все кнопки записи и контактная форма переводят посетителя в WhatsApp. Ссылки Instagram, Telegram, WhatsApp и email хранятся в объекте `settings` в начале `app.js`. Поле `youtube` оставлено пустым: после добавления URL канал автоматически появится в контактах без изменения структуры страницы.

Раздел `#/blog` используется как библиотека бесплатных практик. Каждая практика имеет отдельную страницу: `#/practice/pranayama` и `#/practice/meditation`.
